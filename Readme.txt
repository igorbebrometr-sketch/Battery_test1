Battery Test Android app

Содержит простой интерфейс с:
- процентом заряда батареи;
- ёмкостью в мАч;
- статусом зарядки;
- напряжением и температурой.

Чтобы запустить:
1. Откройте проект в Android Studio.
2. Подключите Android SDK.
3. Синхронизируйте Gradle.
4. Запустите приложение на устройстве или эмуляторе.

Файл главного экрана: app/src/main/java/com/example/batterytest/MainActivity.kt
